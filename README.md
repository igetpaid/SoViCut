# 🎬 SoViCut

**SoViCut** — лёгкий видеоредактор для Windows с упором на управление аудиодорожками. Создан для быстрой обработки видео без тяжёлых программ вроде DaVinci Resolve.

## ✨ Возможности

- **Drag & drop** видео в окно или выбор через диалог
- **Обрезка видео**:
  - Оставить первые N секунд
  - Вырезать последние N секунд (удаление титров TikTok/YouTube)
- **Быстрый экспорт** без перекодирования (если возможно)
- **Сохранение** в папку Загрузки
- **Тёмная тема** интерфейса

## 🚀 Установка

Скачайте последний релиз с [GitHub Releases](ссылка) и запустите `SoViCut.exe`.  
Никакой установки не требуется.
