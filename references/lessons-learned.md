# Накопленные уроки проекта

## Как использовать
Этот файл обновляется только с разрешения пользователя. После важного события Better Program предлагает добавить правило.

---

## Уроки

### 1. Filter-graph вместо extract-then-concat
**Дата:** 2026-06-14
**Контекст:** Экспорт видео с нарезкой клипов — ConcatStrategy использовала N ffmpeg процессов для извлечения сегментов + 1 для склейки. Temp-файлы, рассинхрон, медленно.
**Правило:** Для нарезки и склейки сегментов одного исходника используй единый `-filter_complex` с `trim`/`atrim` + `concat`. Один процесс, ноль temp-файлов, frame-accurate.

### 2. `-ss` после `-i`, никогда до
**Дата:** 2026-06-14
**Контекст:** `-ss` перед `-i` ищет keyframe → кадровая неточность. `-c:v copy` усугубляет.
**Правило:** Если нужна кадровая точность — никогда не используй `-ss` перед `-i` с `-c:v copy`. Используй фильтры `trim`/`atrim` или `-ss` после `-i` с перекодированием.

### 3. PTS-STARTPTS vs PTS-STARTPRES
**Дата:** 2026-06-14
**Контекст:** Опечатка в константе ffmpeg — `PTS-STARTPRES` не существует.
**Правило:** Любую константу ffmpeg сначала проверяй в документации. `STARTPTS` = PTS start PTS, `STARTPRES` не существует.

### 4. Все UI-тексты — через локализацию
**Дата:** 2026-06-14
**Контекст:** Хардкоженные строки в виджетах ломают переключение языка.
**Правило:** Каждый видимый пользователю текст — через `AppLocalizations.t()`. Ключи добавляются во все locale-файлы. Нет `Text('literal string')` без локализации.

### 5. Перед коммитом — проверь регрессии
**Дата:** 2026-06-14
**Контекст:** После перехода на FilterGraphStrategy появилась опечатка STARTPRES, которая не поймалась бы без логов.
**Правило:** Перед каждым коммитом — grep по fixed-bugs.md. Если хоть один шаблон совпал — это рецидив, не коммитить.

### 6. Конфигурация ffmpeg — всегда валидировать
**Дата:** 2026-06-14
**Контекст:** `-vsync` deprecated, заменён на `-fps_mode`, но всё ещё работает. Константы ffmpeg зависят от версии.
**Правило:** Критические параметры ffmpeg должны логироваться и проверяться. При обновлении ffmpeg — проверь, что все флаги актуальны.

### 7. Профессиональный UI требует темы и локализации с первого дня
**Дата:** 2026-06-14
**Контекст:** Проект начинался с одной темы, потом добавляли Dark, потом Twilight. Каждый раз — рефакторинг цветовой системы.
**Правило:** С первого коммита закладывай: темы (Light/Dark) + локализация (минимум EN + RU). Цвета через единый `ColorSet`.

### 8. Git — только с разрешения пользователя
**Дата:** 2026-06-15
**Контекст:** Автоматический commit/push без вопроса лишил пользователя контроля над репозиторием.
**Правило:** Никогда не коммитить и не пушить без явного «да». Перед коммитом — показать `git status` + `git diff`.

### 9. Аудио должно быть включено по умолчанию
**Дата:** 2026-06-15
**Контекст:** `_audioEnabled` по умолчанию было `false`, поэтому при экспорте аудио не сохранялось. Пользователь должен был вручную включить аудио.
**Правило:** Если пользователь не менял настройки — выход должен совпадать со входом. Видео со звуком → экспорт со звуком.
