# Паттерны ошибок

## Принцип
Если ошибка исправлена один раз — она НЕ должна повториться.

## Типичные паттерны

### 1. Ошибка формата
**Когда:** Несовпадение форматов входа/выхода
**Причина:** Использован сжатый формат вместо исходного
**Решение:** Сохранять формат пользователя по умолчанию
**Правило:** Входной формат = выходной, пока пользователь не изменит настройки

### 2. Побочный эффект изменения
**Когда:** Добавление независимой функции ломает существующую
**Причина:** Нарушена модульность, скрытые зависимости
**Решение:** Рефакторинг для изоляции компонентов
**Правило:** Добавление UI ≠ изменение бизнес-логики

### 3. Дублирование логики
**Когда:** Одна и та же ошибка в разных местах
**Причина:** Дублированный код вместо общего модуля
**Решение:** Вынести общую логику в отдельную функцию/модуль
**Правило:** DRY — Don't Repeat Yourself

### 4. Неполный рефакторинг
**Когда:** Исправлена часть функции, остальная осталась
**Причина:** Поиск по точному совпадению вместо паттерна
**Решение:** Поискать все вызовы функции, не только объявление
**Правило:** При рефакторинге — найти ВСЕ использования

### 5. Константа ffmpeg без проверки
**Когда:** Использована несуществующая константа ffmpeg (`PTS-STARTPRES`)
**Причина:** Написано на глаз, без сверки с документацией
**Решение:** Проверять все константы ffmpeg в официальной документации
**Правило:** Любая константа ffmpeg = `man ffmpeg-filters` или официальный референс
**Grep-шаблон:** `STARTPRES`

### 6. `-ss` перед `-i` с copy-кодеком
**Когда:** Keyframe desync при нарезке видео
**Причина:** `-ss` перед `-i` ищет ближайший keyframe, а не точный кадр
**Решение:** Использовать фильтры `trim`/`atrim` (всегда frame-accurate)
**Правило:** Если нужна кадровая точность — `-ss` только после `-i`, и без `-c:v copy`

### 7. Множественные ffmpeg процессы вместо filter_complex
**Когда:** Экспорт видео с нарезкой — N ffmpeg для извлечения + 1 для склейки
**Причина:** Незнание `-filter_complex` и `concat` фильтра
**Решение:** Единый `-filter_complex` с `trim` + `concat`, один процесс
**Правило:** Один вход → один ffmpeg процесс

### 8. `concat=n=1`
**Когда:** Экспорт с одним клипом падает с ошибкой
**Причина:** FFmpeg не поддерживает `concat=n=1`
**Решение:** Специальный случай в коде — если n == 1, не использовать concat
**Правило:** Concat только при n > 1

### 9. Аудио выключено по умолчанию
**Когда:** Пользователь загружает видео со звуком, а экспорт выходит без звука
**Причина:** `_audioEnabled = false` по умолчанию, пустой список треков передаётся в экспорт
**Решение:** `_audioEnabled = true` по умолчанию, кнопка называется «Настроить аудио»
**Правило:** Вход = выход. Если у видео есть звук, экспорт должен его сохранять
**Grep-шаблон:** `_audioEnabled = false` или `enabled = false` в audio_provider
