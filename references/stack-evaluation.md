# Оценка технологического стека

## Когда применять
- Новый проект
- Смена направления существующего проекта
- Пользователь просит создать программу без указания технологий

## Алгоритм оценки

### 1. Определи требования
- Какие функции нужны? (GUI, CLI, web, mobile)
- Какие платформы? (Windows, macOS, Linux, web, mobile)
- Какие ограничения? (производительность, память, время разработки)
- Есть ли зависимости? (API, базы данных, библиотеки)

### 2. Предложи варианты
Для каждого варианта укажи:
- **Название стека** и основные компоненты
- **Плюсы** — почему подходит
- **Минусы** — ограничения и риски
- **Платформы** — где работает
- **Зрелость** — стабильность экосистемы
- **Скорость разработки** — быстро/средне/медленно

### 3. Формат представления
```
## Вариант 1: [Название]

**Стек:** [компоненты]
**Платформы:** [список]
**Плюсы:**
- [преимущество 1]
- [преимущество 2]

**Минусы:**
- [ограничение 1]
- [ограничение 2]

**Зрелость:** [высокая/средняя/низкая]
**Скорость разработки:** [быстро/средне/медленно]
```

### 4. Жди выбор пользователя
НЕ начинай разработку до подтверждения стека.

## Частые ошибки
| Ошибка | Почему | Решение |
|--------|--------|---------|
| Выбор стека без оценки требований | Потеря времени на неподходящий инструмент | Всегда начинай с требований |
| Игнорирование платформы | Стек не поддерживает целевую ОС | Проверяй поддержку ПЕРЕД выбором |
| Выбор по популярности, а не по подходит | Модный стек ≠ правильный стек | Сопоставляй с требованиями |
| Начало кодирования до выбора стека | Двойная работа при смене стека | Стек → план → код |

## Пример хорошей оценки
Пользователь: «Сделай видеоредактор для Windows»

Вариант 1: **Electron + React**
- Платформы: Windows, macOS, Linux
- Плюсы: богатая экосистема, быстрая разработка UI
- Минусы: высокое потребление RAM, медленная обработка видео
- Зрелость: высокая

Вариант 2: **Tauri + React**
- Платформы: Windows, macOS, Linux
- Плюсы: низкое потребление RAM, нативная скорость
- Минусы: меньшая экосистема, сложнее работа с медиа
- Зрелость: средняя

Вариант 3: **C++ / Qt**
- Платформы: Windows, macOS, Linux
- Плюсы: максимальная производительность, полный контроль
- Минусы: длинная разработка, сложный UI
- Зрелость: высокая

→ Пользователь выбирает исходя из приоритетов.
