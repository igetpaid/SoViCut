# Стандарты качества UI SoViCut

## Принцип
UI — это архитектура, не косметика.

## Требования

### 1. Локализация: русский + английский
- Весь видимый пользователю текст — через `AppLocalizations.t('key')`
- Ни одной хардкоженной строки в `Text('...')`
- Каждый ключ существует во всех locale-файлах (`assets/locales/en.json` + `ru.json`)
- Исключение: технические логи, отладочные `print()`, метаданные ffmpeg, кодеки (AAC, MP3, H.264 — стандарты индустрии)

### 2. Темы: светлая + тёмная + twilight
- Приложение поддерживает Dark, Light и Twilight темы
- Цвета — через единый `AppColors`, не хардкожены
- `Color(0x...)` и `Colors.*` — только в `app_colors.dart` или с явным обоснованием

### 3. Консистентность
- Интерфейс не ломается при переключении языка
- Интерфейс не ломается при переключении темы
- Единая сетка отступов (4px, 8px, 12px, 16px, 24px)

### 4. Шрифты
- Минимальный размер для основного текста: 12px
- Для второстепенных подписей (чипы, метаданные, прогресс-бар): от 9px
- Единый набор шрифтов: системный (sans-serif)

### 5. Иерархия
- Визуальная иерархия: заголовок > подзаголовок > текст > подписи
- Один фокусный элемент на экране
- Цвет выделяет важное, а не всё подряд

### 6. Отзывчивость
- UI реагирует на действия: hover, focus, active состояния
- Нет «мёртвых» зон — кликнули, но ничего не произошло
- Загрузки индицируются (прогресс-бар экспорта)
